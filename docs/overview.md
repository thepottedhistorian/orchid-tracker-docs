# System Overview

The Botanical Archivist (Orchid Tracker) is a desktop application designed to maintain structured, archival‑grade records of orchid specimens. It provides growers, archivists, and developers with a unified interface for inventory management, care logging, bloom tracking, photo documentation, and long‑term archival.

---

## 🌿 Purpose of the Application

The Orchid Tracker exists to solve a simple problem: orchid recordkeeping is tedious, fragmented, and often inconsistent. This application provides:

- A clean, unified inventory ledger  
- Passport Files for each specimen  
- Relational care logs (watering, repotting, bloom, observation)  
- Bulk operations for large collections  
- Spreadsheet ingestion for fast onboarding  
- A full‑screen Passport Modal for deep specimen analysis
